How to import

  1. Launch HELLGATE and tap Settings.
  2. Tap Save data.
  3. Tap inside the code box below, Select All, Copy. (A plain-text copy is also at reviewer-save.txt.)
  4. Paste the whole line into the Save data field and tap Import.
